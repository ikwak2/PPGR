# CONTEXT-CONDITIONED MODALITY GATING FOR IN-THE-WILD WEARABLE PPG _ BIOMETRIC VERIFICATION ON UNSEEN USERS

- about dataset
  - The dataset we used is *WildPPG*   https://siplab.org/projects/WildPPG
  - We use wrist **green-PPG**, **3-axis ACC (x/y/z)**, and **internal device temperature (Temp)** from 16 participants in WildPPG. The **240–540-minute** recording interval is divided into five consecutive 60-minute temporal blocks. Evaluation uses four subject-disjoint folds, with no overlap between training and evaluation participants.
